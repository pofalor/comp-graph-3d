# Компьютерная графика — 3D-моделирование

Трёхмерные сцены и модели, выполненные в **Blender**.

## Содержание

| Файл | Описание |
|------|----------|
| [night_castle.blend](night_castle.blend) | Итоговая сцена — ночной замок |
| [lightning/lightning.blend](lightning/lightning.blend) | Модель освещения сцены |
| [lightning/lamp.blend](lightning/lamp.blend) | Модель лампы |
| [render](render) | Отрендеренные изображения |

Модели дополнительно выгружены в обменные форматы `.fbx` и `.dae` — их можно открыть без Blender, например в игровых движках или просмотрщиках 3D.

Файлы `.blend1` — автоматические резервные копии предыдущей версии, создаваемые Blender при сохранении.

## Как открыть

Открыть `.blend` в Blender (`File → Open`). Рендер запускается клавишей `F12`, результат сохраняется в `render`.
